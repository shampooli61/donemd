# Done.md 领域约定

- 文档：一个磁盘 `.md` 文件对应一个文档窗口。产品是单文件阅读／编辑器与飞书桥，不管理 vault、不做 RAG。
- Visual 视图：可编辑的富文本正文；Markdown 源：只读、可复制的实时源码镜像，最终设计不开放双向编辑。
- 文档大纲：按标题导航和折叠；选区浮窗：作用于当前编辑选区的格式与 AI 操作。
- 稳定规范化：第一次保存可能统一 Markdown 写法，之后序列化保持稳定。只有规范化实际改变原文件时才需首次提示。
- 原文块：暂不能可视化编辑的源语法，磁盘逐字保留；使用独立原文编辑器修改，不能引导去只读镜像编辑。
- 飞书占位块：飞书专有内容的指针，保留远端身份，不在本地编辑其内部内容。
- 本地视频：本地 assets 文件，以标准 video HTML 保存；当前不上传到飞书，保留本地并明确告知限制。
- 同步根目录：用户选择的本地文件夹，不是应用内数据库。
- 写入完成和核验完成：两个不同结果。核验失败不能标记为已完整同步；绑定仍需保存，避免重复创建文档。

历史私有开发文档中的会话资料和凭据不进入公开仓库。本文件保留本轮实际使用的稳定业务约束，具体取舍见 docs/adr。

## iOS 文档端
- 手机文档：同一个 `.md` 文件的移动视图，完整写作，源码仍只读。
- 文档文件夹：用户授权的真实目录，用于浏览文件与访问相邻附件，不是笔记库，不等于飞书同步根目录。
- 本地已保存：本机写入成功，不代表另一台设备已接收。
- 冲突副本：并发修改时保留的独立内容；首版由用户选择，不自动合并。
- 已确认首版范围见 docs/prd/ios-document-editor.md；架构见 docs/adr/ios-document-storage.md。
