# 马上做完：iOS 原生编辑交互规范

版本：2026-10-30 / 交互方案 v1。面向现有 iOS 移动分支，供 Pluso 实现；本文件是设计，不是已实现、已验收或已发布说明。

## 1. 本轮范围与原则

用户已暂停复杂真机验收，现有未验收项目保留“待验收，已暂停”。本轮优先解决操作难找、成排网页按钮挤占正文、键盘操作割裂的问题。参考备忘录的“正文优先、常用操作在系统栏、复杂操作进面板”，不是复制其完整功能。

保留 Tiptap/WKWebView 正文、Markdown 编解码、附件落盘、权限、保存、恢复与冲突保护。迁移交互壳与命令入口，不重写正文编辑器，不新增 AI、登录、云服务、删除文件或文件夹创建能力。不把只读源码改成源码编辑器，不加入编辑中重命名，不把目录搜索升级成全文库搜索。

本轮不做目录+正文双栏改造。展开内屏让正文和当前操作面板形成“主内容+临时工具”的关系；大纲、格式等仅按需出现，不默认永久占据半屏。

核心变化：删除常驻网页顶端“阅读/源码/大纲/阅读设置”和底部九项文字工具行。用系统 `.toolbar`、`Menu`、`ToolbarOverflowMenu`、`.sheet`、`.popover`、`Form`/`List`、系统选择器替代。不要在 SwiftUI HStack 或 HTML 中手绘一列右侧按钮。

## 3. 视觉基础：安静、可预测，不做装饰主题

唯一应用强调色：浅色 #0066CC，深色 #66AAFF；用于可操作符号、选择态、插入点，不给每类工具不同颜色。原因：与系统操作语义一致、在白/黑背景可读，不照搬 Notes 黄色。

语义色优先，下面为预览与必要网页匹配值：

| Token | Light | Dark | SwiftUI |
|---|---|---|---|
| 正文底 | #FFFFFF | #000000 | systemBackground |
| 分组底 | #F2F2F7 | #1C1C1E | secondarySystemGroupedBackground |
| 正文 | #1C1C1E | #F2F2F7 | primary / label |
| 次要字 | #636366 | #AEAEB2 | secondary / secondaryLabel |
| 分隔线 | #D1D1D6 | #48484A | separator |
| 强调 | #0066CC | #66AAFF | app tint |
| 错误 | 系统 red | 系统 red | red，仅图标/标题；说明仍 primary |

普通字对比 ≥4.5:1、大字/有意义图形 ≥3:1；系统禁用控件不当成唯一信息。成功用 checkmark+文字，不新增绿色品牌色。系统玻璃只给系统工具栏/原生浮层，网页背景不仿玻璃，不另画栏背景。

现有阅读主题继续保留，仅作用于正文，不染色系统工具栏与菜单：纸质 #F7F1E4、深色主题 #101820；正文在相应背景使用现有可读文本色，主题不引入新的工具强调色。

系统字体 `.default`：导航标题 inline 17 semibold；正文17 regular、默认行高约29.75（保留原1.75倍）；正文H1 28 bold/H2 22 semibold/H3 20 semibold；菜单和表单17 regular；节标题13 semibold；辅助说明13 regular；源码15 monospaced。SwiftUI 用语义字号并支持 Dynamic Type，不把 pt 固定为 frame 高度。正文保留用户15/17/19/22/26字号档，系统辅助字号继续相对放大，不以此阻止放大字体。

间距基准4/8/12/16/20/24/32 pt。正文外屏左右18pt、展开左右28pt（安全区内部）；段间16pt，标题后12pt。展开正文可用宽最大720pt，靠内容区域leading布置，剩余宽度用于按需工具面板而非永久中缝。系统面板内容边距20pt或系统Form默认；行最小44pt，说明换行时自动增高；组间24pt。原生控件不覆盖系统规定的布局/角半径；仅自定义消息容器圆角12pt、内距12pt。

## 4. 导航与系统栏

仍保持目录 → 全屏编辑器的现有会话生命周期；编辑器内部 NavigationStack。退出必须调用现有 requestSave(returnToList:true)，不得直接 dismiss，首次格式确认/保存失败时继续留在原文。返回旁白为“保存并返回目录”，可视符号chevron.backward；系统常规返回无第二个自制返回按钮。

Duo外屏、横向内屏由系统将栏放在侧边（通常右侧）；内屏纵向、普通iPhone和iPad按平台规则在顶部/底部。不硬编码right、固定rail宽或camera位置；Split View和RTL让系统决定侧边位置，禁止强制所有姿态一律右侧。

一级栏视觉以SF Symbol图标为主，同类操作合成一个入口，点开在触发图标旁显示系统Menu/popover；不展开一列文字按钮。所有ToolbarItem使用Label（操作名+SF Symbol，供系统选择呈现与辅助功能使用），不是要求侧边栏同时显示文字，所有菜单项也尽量Label。工具栏不用定宽自定义View、不用文字按钮伪装符号、不依赖Spacer手排。只保留一个系统溢出菜单；不同时保留自制“文档操作…”和系统“…”。旧系统无ToolbarOverflowMenu时降级单一原生Menu。

### 4.1 编辑态工具分组

| 次序/组 | 操作 | SF Symbol | 行为/优先级 |
|---|---|---|---|
| 导航 | 保存并返回目录 | chevron.backward | 顶端导航，最高，保留现有保存保护 |
| 当前任务，仅键盘活跃 | 收起键盘 | checkmark | 提交当前组合后收键盘；不退出、不转阅读、不显示“已保存”假成功；高 |
| 编辑组 | 撤销与重做 | arrow.uturn.backward | Menu内“撤销”“重做”；两项状态由网页历史驱动，高于插入，低于格式 |
| 编辑组 | 格式 | textformat | 原生格式面板，高优先级 |
| 内容组 | 插入 | paperclip | 原生插入菜单，普通优先级 |
| 系统溢出 | 更多 | ellipsis | 包含低频动作与系统溢出的工具 |

默认键盘收起为导航+撤销菜单+格式+插入+系统更多五个逻辑入口；键盘弹出增加收起键盘。不硬保证全部六个同时可见：高度不足先溢出插入，其次撤销菜单；保留返回、收起键盘、格式与系统更多入口。溢出的项保留文字与符号，不改变命令能力。不得把更多本身溢出到不可达。

撤销不直接调用SwiftUI/UIDocument的undoManager来替代Tiptap历史。Menu多一步换来重做可发现且不会把两枚按钮常驻占满栏；可保留键盘快捷键，不能要求用户靠长按或摇动才找到重做。

阅读模式不常驻一枚切换按钮：进入阅读放系统更多，进入后格式/插入/撤销隐藏，原位提升“编辑”square.and.pencil为高优先级；标题附辅助“只读”。查找、大纲、源码、阅读设置、分享、恢复列表仍可浏览。恢复/写操作按只读约束及显式退出阅读处理，不绕过只读guard。

### 4.2 系统更多菜单顺序

1. 导航与阅读组：查找与替换 magnifyingglass；文档大纲 list.bullet.indent；阅读模式 book（阅读态“编辑”square.and.pencil）；查看Markdown源码 chevron.left.forwardslash.chevron.right。
2. 文档组：分享 square.and.arrow.up → Markdown文件 / 文档与附件；保存 tray.and.arrow.down；恢复版本 clock.arrow.circlepath。
3. 当前块组：段落 paragraphsign；编辑所选内容 pencil（未选中代码/公式/表格/附件时禁用，并由面板解释，不改变目标）；阅读设置与统计 textformat.size。
4. 根据系统宽度溢出的格式/插入/撤销入口，由系统加入，不手工再复制一次。

不在菜单新增删除文档、移动文件、重命名当前打开文档、扫描、录音等未实现能力。分享仍走现有先保存，再生成分享文件；含附件与纯Markdown分两项。

## 5. 各屏幕与面板

### S1 目录/初次授权（保留原生List）

inline/large title依现有目录层级，一级目录名；搜索使用系统searchable“按文件名查找”。主内容List：目录行folder / 文档行doc.text，文件名17，行≥52pt；父目录导航照旧。新建使用square.and.pencil作为主操作，文件夹/离线/刷新进单一系统更多；未授权时隐藏新建，仅主按钮“选择文档文件夹”。

无授权：ContentUnavailableView(doc.text)，标题“接着写你的文档”，沿用现有说明和选择文件夹按钮，不新增账户引导。目录空：doc，标题“文件夹里还没有文档”，按钮“新建文档”；搜索无结果：magnifyingglass，标题“没有匹配的文件名”，保留搜索与清除。

文件contextMenu保留重命名、创建副本、分享文件；不新增删除。重命名原生alert+TextField，取消/确定，空/非法/重名失败在对话内容说明并保留输入，不能假成功。

来自文件App待处理：原生section显示文件名与当前授权步骤，最多一个主操作（选择所在文件夹/重试打开）和必要的重新授权、取消打开；失败可见且不盖住目录。正在打开ProgressView，加载期间禁止重复请求，取消路径保留。

### S2 编辑页：外屏

系统inline标题仅文件名，单行尾截断；不再额外显示常驻保存说明行。正文占满系统栏和safe area之外可用高度。没有上下网页工具条；所有文字输入、勾选、折叠标题、附件点击保持直接操作。

正文内容为空时仅占位“开始写作…”（secondary，17），有文字即消失；文件名仍在导航标题，不自动把文件名插入正文。不自动弹键盘，点正文才聚焦。若现有文件模板已经带标题，尊重内容，不额外再插入一份标题。

普通保存状态藏入标题的辅助状态/文档信息：正常不占正文。保存中在导航标题相邻以系统进度/辅助描述表达；保存完成无需常驻“iCloud由系统同步”的句子；文档信息中保留“已保存到本机，云同步由系统处理”。发生首次格式确认、保存失败、冲突、权限失败等阻断时必须出现明显消息区（S11），不能把问题只藏进更多。

### S3 编辑页：展开内屏与半折

同一正文/选区/文档对象，不重载编辑器，不以deviceId切屏。正文按可用宽度 reflow，保持相同字号；临时格式/大纲面板在系统靠近调用者的popover/sheet内呈现，不永久挂一列文件列表。本轮不把页面切成等宽两半。

完全展开无永久折缝；背景和媒体可连续跨过中心。半折时系统栏与sheet自动避开保留区；自定义网页正文要按实际可用区域检查文字/控制遮挡，必要时配合本地reserved-region布局，不以固定中间padding代替。不要在每次hinge变化时关闭面板、丢选区或切换模式。

### S4 键盘弹出 / 中文组合输入

系统栏继续可用；无网页写作底条，也不额外加一根自制键盘文字工具栏。使用系统键盘、候选栏、选择/复制/粘贴菜单，系统已有输入附件栏不额外复制。收起键盘在系统栏，与返回严格区分。

正文滚动容器截止在键盘可视边界，当前整行与插入点至少距遮挡边界8pt；不能把键盘高度同时从SwiftUI和网页各减一次。取消旧工具栏后更新viewport计算，禁止保留一块空白工具栏占位。

点格式/插入先记住选区与滚动位置；sheet可以按系统规则收键盘。取消返回时恢复原选区，不滚到开头、不强制聚焦错误节点。组合输入未提交时，收起键盘和改格式不得截断拼音；由实现层安全提交/等待compositionend再执行，等待时禁用写操作并用ProgressView/旁白说明“正在完成输入”。不能自行将拼音字符串当正文提交。

### S5 格式面板（native Form，非网页dialog）

toolbar Label“格式”/textformat；优先使用锚定格式图标的系统popover（preferred width 340pt，理想高470pt，最大可用高-32pt，内容滚动）。外屏也优先近手弹出，不仅按compact类别自动改成大sheet；实现核对系统popover的compact adaptation支持。若实际可用区域不足、辅助字体导致难以操作或系统要求适配，才降级medium/large sheet，纵向不足直接large。系统半折保留区优先，不手工固定弹窗坐标。标题“格式”，关闭xmark（取消只关面板，不撤销已执行即时格式）。

从上到下：
- 文本样式：Picker/list 正文、标题1、标题2；“更多标题”展开H3–H6；当前样式checkmark。
- 字符样式：原生Toggle/button四项 粗体bold、斜体italic、删除线strikethrough、行内代码chevron.left.forwardslash.chevron.right；选中背景tint 12%+选中语义，混合选区允许mixed。
- 列表：无序list.bullet、有序list.number、待办checklist；使用同一现有命令，不改变列表数据结构。
- 段落：增加缩进increase.indent、减少缩进decrease.indent、引用text.quote、提示块info.bubble。
- 次要：清除格式、编辑链接link（进入S8）。分隔线移至插入菜单。

即时动作成功不关闭格式面板，选择结果通过网页状态回传刷新；不重置全文或触发save/load。表格内不支持标题时disabled且显示说明“表格内暂不支持标题”；保护锁/只读时禁用修改并给原因。

### S6 插入菜单与系统选择器

短选项一律优先锚定触发图标的系统菜单；撤销与重做、插入及更多遵循相同规则。需要文字输入、复杂预览或系统照片/文件选择时才进入相应表单/系统页面，不把所有操作默认做成全屏。

paperclip → Menu分组：
- 图片与视频：从照片选择photo.on.rectangle；从文件选择folder（沿用系统picker，单选图片/视频）。
- 内容：表格tablecells、链接link、分隔线minus、公式function → 行内/独立、代码或图表curlybraces、原文块doc.plaintext。

点击media优先记住选区，导入成功后按现有块插入规则，在原选区所属顶层块之后插入，或替换原选中的同类附件，不重置焦点到开头。导入中禁用重复插入、显示进度，可取消系统选择器；取消不显示错误。失败保留文档与原引用，提供重试，不删除磁盘附件。

表格native Form：行/列Stepper+数字输入，默认3×3，行1–100，列1–20；显示“首行为表头”，取消/创建。无合法值时创建disabled。代码/公式/原文转S8，不把高级内容直接堆到一级栏。

### S7 查找与替换

系统更多进入native查找面板，compact为large sheet、regular为popover（340pt，滚动）；顶部系统TextField“查找内容”，下方显示“当前/总数”，上一处chevron.up、下一处chevron.down，关闭xmark。选择替换后展开“替换为”与“替换第一处”“全部替换”。阅读模式不显示替换操作。

复用现有字面匹配、高亮、跨折叠展开命中逻辑；不新增正则/大小写开关。需把查找高亮滚入正文视野；提交搜索或点“下一处”后关闭查询面板并滚入命中；在系统栏临时替换格式/插入组为上一处、下一处、关闭查找三项，匹配计数放文档标题辅助，不把自定义计数View塞进竖栏。再次从更多选择“查找与替换”可编辑查询/替换。关闭查找清除高亮并恢复普通工具栏。查找导航必须在关闭面板后仍可继续，不能有命中却被sheet遮住。

无查询：“输入要查找的文字”；无结果：“没有匹配内容”，上一/下一disabled。替换结果显示“已替换N处，可撤销”，不toast称保存完成。替换第一处沿用全文第一处的当前语义，不写“替换当前”误导。中文组合查询完成后更新匹配，不能夺走键盘焦点。

### S8 链接 / 代码 / Mermaid / 公式 / 原文编辑

有输入的面板统一native NavigationStack+Form，compact large sheet，regular系统sheet/popover，标题按对象：“链接”“代码与图表”“公式”“原文块”；取消/应用或保存内容。使用系统TextField/TextEditor承载纯文本输入、网页仅渲染预览，不以HTML dialog作外壳。源码编辑区15 monospaced，预览区标题13 semibold；垂直布局“输入→预览”，不固定等高对半；可滚动。

链接预填现有地址；空值应用=移除链接，说明明确；仅http/https/mailto/#；非法地址在输入下方可读error，不关闭面板。

代码语言字段，仅代码显示；填mermaid切图表预览。公式行内/独立沿用选择；原文块保留原字符串。语法错误显示“预览暂不可用，原文会保留”，不擦输入，保存限制遵循原有commitRichNode能力。保存成功关闭回到节点；失败保留面板输入。

### S9 大纲 / 源码 / 阅读设置

大纲：原生List，H1–H6相对缩进每级12pt（窄屏最大48pt，仍提供标题级别旁白），空标题显示“空标题”；行标题可点击导航，末端独立折叠chevron，44pt目标。无标题ContentUnavailableView(list.bullet.indent)“文档还没有标题”。当前跳转会展开折叠，保留原语义。外屏sheet、内屏popover；不默认固定侧栏。

源码：原生只读页面（仍可嵌现有CodeMirror只读内容视图），标题“Markdown源码”，清楚标“仅供查看，不能在此编辑。”；toolbar关闭xmark、复制doc.on.doc；不提供保存按钮。打开前获取最新安全快照但不强制写盘，不能展示过期已保存文本冒充当前正文。复制成功辅助提示“已复制源码”；失败可长按选择复制。

阅读设置：native Form，分组外观（跟随系统/纸质/赛博夜色）、字号（15/17/19/22/26，动态字体叠加按系统辅助设置）、统计（正文非空白字符数、源码UTF-8字节数）。保留原localStorage偏好迁移，不抹用户设置。只有显式选主题才变，工具壳始终跟随系统。

### S10 段落 / 表格 / 附件上下文操作

段落操作在更多可达，也可加入原生contextMenu；不要求长按才能找。上移arrow.up、下移arrow.down、创建段落副本plus.square.on.square、删除段落trash（destructive）。副本是就地复制块，不是剪贴板；入口统一显示“段落”，上下移动显示“上移段落”“下移段落”。“删除段落”可撤销；空/边界项disabled，不能误把整份文档删除。

编辑所选内容依当前节点路由：代码/公式/原文转S8；表格Menu显示前/后插行、前/后插列、删除当前行/列/表格，破坏性项独立组；附件Menu预览、编辑图片描述、替换（同类型选择照片/文件）、删除此引用。旧磁盘附件保留；删除按钮label必须“删除此引用”，不能“删除文件”。未命中对象时说明“先点选要编辑的内容”，不偷偷选最近段落。

表格全屏与返回仍复用现有能力，入口符号arrow.up.left.and.arrow.down.right，关闭xmark，全屏占正文而非盖住系统栏/键盘；表格横向滚动、代码横向滚动保留。

### S11 重要状态与恢复版本

非阻断状态（保存中/已保存本机/统计）放文档标题辅助或文档信息，避免每次输入上方跳出一大条；旁白节流播报。必须保留的阻断横幅：权限失败、保存失败、冲突、待打开另一文档、首次格式确认。最多一个主要横幅，其他消息通过展开“详情”查看，不重叠占据全部正文。

横幅用原生容器，12pt内距，图标20pt，标题callout semibold，说明callout，按钮使用可伸缩Button行/垂直布局；无固定高度。错误图标exclamationmark.triangle，信息info.circle，冲突doc.on.doc；不用只靠红字。错误不自动消失。

首次格式确认：保留明确说明“首次保存会统一Markdown格式，这不是iCloud同步开关”。可在编辑页收成“首次保存需要确认”信息行+“查看说明”，但显式保存时必须用原有alert让用户确认并保存/继续编辑；不偷换为一次授权以后总自动允许。用户没确认不能显示“已保存”。

另一个文件待打开：文件名、取消待打开、保存并返回目录后继续（沿用当前协调流程，不能直接覆盖正文）；失败留在当前文档。

冲突：标题“发现其他版本”，保留动作“保留所有版本并加载磁盘内容”，提供细节；先flush最新输入、保护备份再替换。加载中写操作disabled；失败不能关横幅假成功。

恢复版本：原生List，日期headline、原因callout、300字以内预览caption（随字体换行）；点条目进入预览/确认，操作“载入此版本（先备份当前内容）”，loading spinner+禁重复。空列表显示“暂无可恢复版本”，说明“不代表原文已丢失”，不提供不存在的恢复保证。错误在sheet内可见，保留关闭；恢复成功关sheet并显示辅助结果，失败留sheet且保留当前输入。

分享准备/附件导入：系统ProgressView+描述，忙碌时相应入口disabled；失败说明+重试；不要把已请求离线下载说成已可离线。PHPicker/文件选择/分享/QuickLook全部保留系统界面，不自制仿系统页面。

## 6. 命令桥、状态与选区：实现契约

当前原生只支持部分媒体/加载命令，网页多数工具为DOM闭包；本方案不是纯CSS调整。增加统一原生命令入口、editorState回传与selection书签，不能让原生按钮调用不可达网页click或只修改SwiftUI状态。

建议命令域：history.undo/redo、format.*、insert.*、search.*、outline.*、mode.*、selection.context、reader.*；语义枚举加白名单，所有消息携带document identity、revision、requestId，拒绝旧文档/旧选区命令。这里是设计契约，不限定具体类型名。

状态应回传：ready/busy/lock/composing、editable、canUndo/canRedo、当前块类型/marks混合态、所选节点类型与可执行动作、书签有效性、查找计数、标题列表/折叠、主题/字号。保护锁与用户只读模式分开；任一保护锁拒绝写命令。错误需要可见响应，不静默吞操作。

原生面板激活时冻结有效选区书签，不替换文档；格式即时动作验证identity/revision后在同一正文transaction执行，更新后书签跟随transaction映射；取消仅关面板。媒体导入等待期间不能拿旧偏移去改另一个文档。不能以重载HTML、setContent、saveNow、重新创建WKWebView来“刷新格式状态”。

阅读/编辑统一一个状态机更新editor.setEditable、网页CSS、原生isReadOnly和可用命令；不能仅发既有setEditable就遗漏网页局部reading状态。只读仍允许复制/查找/大纲，禁止节点写操作，保持MobileReadOnlyGuard。

保留 composition / snapshot sequence / flush / replacementLock+ACK / recovery checks / file identity 的现有保护。收起键盘不写盘成功假提示，保存不等于收键盘。系统Undo与网页Undo不得产生两套历史。表单代码输入的新草稿也不得因旋转重建丢失。

命令按顺序排队并给执行/拒绝回执，不能复用现有单槽outgoing假设多条连续动作必达；附件块维持“所在顶层块之后插入”的现有规则，不承诺任意字符位置插入。

阶段迁移：先补桥与状态→迁移格式/插入/撤销/模式/更多→搜索/大纲/源码/高级输入面板→隐藏旧网页导航。不能先删旧入口后只交付半套命令；正常发布路径不得让用户看见原生与网页同一功能重复两份。过渡保留仅限开发调试开关，不对用户暴露。

## 7. 可访问性与适配验收（由团队验证，不要求用户重跑复杂清单）

- 每项≥44×44pt，符号20–22pt；系统默认尺寸优先。所有符号有中文Label，旁白：保存并返回目录、收起键盘、撤销与重做、格式、插入、更多操作。选中项读已选中/混合，不靠颜色。
- 面板打开焦点到标题，关闭回到触发控件/原选区；正在组合输入时不抢焦点。动态字体变大允许所有Form行换行与滚动，不缩字硬塞；菜单始终有低频项的可达路径。
- 折叠/展开/旋转/分屏不重建会话、不清空选区、不让弹层落到保留区。内屏纵向允许系统水平栏，不以“必须右侧”破坏原生行为。
- 键盘态检查当前整行与末行≥8pt安全间距、无网页工具残影、无二重keyboard inset。面板开关后对选中段落格式修改正确，不误改另一块；中文组合不丢字、不提前写入半个拼音。
- 保存失败禁止退出，格式同意必须显式确认，恢复/冲突先保留最新输入，媒体引用/磁盘文件语义不变。
- 浅/深色、增加对比度、减少透明度、放大字体和旁白由开发/设计检查；尚未验证的仍标待验收。用户真机验收继续暂停，除非用户主动恢复。
