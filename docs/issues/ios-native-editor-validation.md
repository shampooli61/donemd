# iOS 原生编辑器实施与验证记录（2026-10-30）

## 范围与边界

- 对照 `docs/design/ios-native-editor.md`；保留原有正文编辑器和持续存在的 WKWebView，不自绘右侧操作栏。iOS 27 使用系统工具栏与系统溢出，iOS 17–26 保留系统导航栏回退。
- 字符格式为紧凑四项分组；文本样式与列表分组。键盘/短窗口/辅助字号使用系统大面板，其他空间使用锚定弹窗，不强行唤起键盘。
- 普通中文组词只禁用冲突操作并提供辅助原因，不显示加载转圈或新增正文状态行。当前未完成组词的操作直接拒绝，不伪造队列等待。
- 未请求发版；PR #112 保持 Draft，所有 Issue 保持开放。用户暂停的真机/iCloud/VoiceOver 验收不恢复、不催验。

## 实现保护

- 命令使用类型化信封、单个在途 FIFO、匹配请求 ACK 与文档身份/revision；JavaScript 求值完成不是操作成功。
- 原选区保存为会随交易映射的 token；组合输入、只读、锁定及过期文档均有拒绝边界。面板关闭恢复选区时不强制聚焦。
- 原生接管成功后才隐藏网页旧工具栏；实时源码只读，先读取当前编辑器内容，不强制提前保存。首次规范化仍需用户确认；快照、恢复、外部修改保护保留。
- 恢复列表逐条解码；坏条目只产生部分读取警告，健康未过期记录照常显示，返回 false。读取不删除、不修复、不重写文件；包含有效/损坏相邻记录字节不变的回归。
- 面板关闭/阅读切换不再误发未知预览；代码/公式/原文预览有独立类型白名单。
