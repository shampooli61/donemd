## 验证证据与边界

- 发布门槛：TypeScript 类型检查通过；前端 9 个文件、40 个测试通过；Swift 581 个测试通过。
- 同步故障注入：不支持内容在 API 调用前拒绝；编码失败零请求；创建拒绝不删除旧正文；分段假成功不删除旧范围；回读失败保留绑定并标记待核验；恢复历史及旧版备份迁移通过。
- 应用内验收：格式修改后原生撤销／重做状态一致；查找定位表格、展开折叠章节；源码栏隐藏；同步限制提前展示；AI 工具栏区分操作和设置，实际面板可打开且辅助功能树显示当前项、名称和作用范围。
- 原文块保存／取消／撤销与 HTML 不执行通过前端集成测试。人工验收发现并修正按钮旧样式阻止点击的问题。
- 多编辑器历史隔离与 AI 面板键盘导航通过前端集成测试；未将其表述为完整多窗口或 VoiceOver 人工验收。
- 图片／视频读入和存储失败均接入原生可见提示；未在用户磁盘上人为制造权限或空间故障。
- 云端破坏性故障使用离线 HTTP／API 注入，不修改用户真实飞书文档。飞书 API 无多请求事务，失败可能保留重复内容，提供版本历史恢复指引。
- 公式／原文块采用提前阻止推送以保护数据；本地视频仍不上传飞书，不声称新增这些格式的云端支持。
