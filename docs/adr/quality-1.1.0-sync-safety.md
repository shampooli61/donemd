# 同步安全与本地恢复（1.1.0）

状态：采用。

飞书写入不具备跨多次 API 调用的事务能力。完整替换和占位块之间的分段替换均先编码、追加新正文，再回读确认旧块身份与新正文一致，最后删除旧正文。创建失败或回读不一致不删除旧正文；部分成功可能留下重复内容，应检查飞书历史版本，不能将失败当作原子回滚。

最终回读使用规范化正文摘要，区分写入请求完成与内容核验完成。核验未完成时保存绑定与期望摘要，提供只读重新核对入口，避免重复创建文档。公式、原文块及无法安全处理的嵌套占位结构提前禁止推送。

每次拉取均保护未保存修改；覆盖前必须成功写入本地恢复版本。每文件保存最近 30 天最多 20 个版本，恢复时先备份当前正文；旧版双文件备份迁移为原子 JSON。恢复记录存于 Application Support，不在用户文档目录生成旁路文件。

Markdown 源仍是只读镜像。原文块通过独立编辑弹层修改，进入同一编辑器撤销历史。查找与章节展开不进入正文历史。AI 面板只在编辑器销毁时清理，插件重配置不得移除其 DOM。
